## What I'm Building

**[CognChain](https://cognchain-program-production.up.railway.app)** — the missing memory layer for AI systems.

Every AI session ends and the insights disappear into vendor databases — inaccessible, non-portable, impossible to prove. CognChain inverts this: high-value AI outputs are crystallized into compact, hash-committed records anchored permanently on Solana. Users own the vault. Agents earn reputation through verifiable history.

> *Not model weights. Not raw logs. Portable, verifiable cognitive checkpoints — owned by the user, trusted by any agent.*
