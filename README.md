## 🧠 What I'm Building

**[CognChain](https://cognchain-program-production.up.railway.app)** — Verifiable AI Memory Layer on Solana

Every AI session ends and insights disappear into vendor databases. CognChain inverts this: high-value AI outputs are anchored permanently on Solana as verifiable, portable cognitive checkpoints — owned by the user, trusted by any agent.

> *Not model weights. Not raw logs. Verifiable cognitive checkpoints — owned by you.*
